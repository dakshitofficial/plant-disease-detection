# 🌿 Plant Disease Detection

An AI-powered **Plant Disease Detection System** that uses a Deep Learning model built with **TensorFlow/Keras** to identify plant diseases from leaf images.

The application provides the predicted disease, confidence score, disease information, recommended treatment, and prevention tips through an interactive **Streamlit web interface**.

---

## 🚀 Features

* 🌱 AI-based plant disease detection
* 📸 Upload leaf images in **JPG, JPEG, or PNG** format
* 🖼️ Supports images of different resolutions
* 🧠 Deep Learning model using TensorFlow/Keras
* 📊 Prediction confidence score
* 🩺 Disease description
* 💊 Recommended treatment
* 🛡️ Prevention guidelines
* 📋 Plant health report card
* 📥 Downloadable PNG report
* 🎨 Interactive Streamlit interface
* 🌿 Animated loading experience

---

* 🍎 Apple

* 🍒 Cherry

* 🍇 Grape
* 🍊 Orange
* 🍑 Peach
* 🌶️ Pepper
* 🥔 Potato
* 🫐 Raspberry
* 🌱 Soybean
